# College Attendance Manager (Android, Kotlin + Gradle)

This is a complete starter mobile app for managing college attendance with a modern Android stack:

- Kotlin + Gradle (KTS)
- Jetpack Compose UI
- MVVM architecture
- Repository layer
- Room-ready local data layer (offline-first design)
- Retrofit-ready network layer
- Multi-role product vision (Admin / Faculty / Student / Parent)

## Features included in this starter

1. Dashboard with KPIs and low-attendance alerts.
2. Courses screen to switch active course.
3. Attendance screen with quick marking actions.
4. Reports screen with per-student percentages.
5. Capabilities screen listing extensible enterprise features.

## Production features planned by architecture

- Biometric / QR / RFID integrations
- Parent notifications by SMS/Email/Push
- Defaulter policy automation and warning workflows
- Export reports as CSV/PDF
- Full authentication + role-based authorization
- Cloud sync with conflict resolution

## Build and run

1. Open `college-attendance-android/` in Android Studio (latest stable).
2. Let Gradle sync.
3. Run `app` on an emulator or device.

> Note: this repository does not include Android SDK itself. Install SDK via Android Studio.
